<h1>ABOUT TRACE</h1>

<p>
TRACE is a parsimonious agent-based model grounded in Pierre Bourdieu's theory of practice. The model explores how artistic career trajectories emerge through interactions between economic capital, symbolic capital, investment dispositions, and cultural field opportunities.
</p>

<p>
TRACE does not predict individual artistic careers. Instead, it is a theory-driven computational model designed to explore how persistent patterns of artistic participation, precarity, success, and exit can emerge from interactions between agents and field structures.
</p>

<h2>TRACE Desktop version</h2>

<p>
TRACE requires the following software:
</p>

<ul>
<li>NetLogo (developed and tested using NetLogo 7.0.4)</li>
<li>Operating system: Windows, macOS, or Linux</li>
<li>No external NetLogo extensions or libraries are required.</li>
</ul>

<p>
To run TRACE, download and install NetLogo, open the <code>TRACE_V01.nlogo</code> model file, and follow the user guide provided for model use.
</p>

<p>
Analysis of simulation outputs may require additional software packages (e.g., R or Python), depending on the analytical approach adopted.
</p>

<p>
The Model User Guide and sample model results data are provided with the model.
</p>
