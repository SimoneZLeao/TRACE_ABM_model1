<h1>TRACE</h1>

<h2>Trajectory Reconstruction through Agent-based Cultural Emergence</h2>

<p>
TRACE is a parsimonious agent-based model grounded in Pierre Bourdieu's
theory of practice. The model explores how artistic career trajectories
emerge through interactions between economic capital, symbolic capital,
investment dispositions, and cultural field opportunities.
</p>
<p>
Model User Guide and sample model results data are provided with the Model.
</p>

<h2>About the model</h2>

<p>
TRACE does not predict individual artistic careers. Instead, it is a
theory-driven computational model designed to explore how persistent
patterns of artistic participation, precarity, success, and exit can
emerge from interactions between agents and field structures.
</p>
